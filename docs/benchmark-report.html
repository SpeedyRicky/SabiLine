Preprocessing & audio protocol

Reference audio is synthesized once per instance from the de-identified reference transcript and the identical waveform is served to every model under comparison, so no model gets a cleaner signal than another. Text normalization before scoring: punctuation stripped, lower-cased, whitespace collapsed, and diacritics deliberately preserved (stripDiacritics: false) — stripping them would silently erase the tonal distinctions this benchmark exists to measure. The live intake path additionally applies gain normalization to quiet microphone input before transcription.

Methodological limitation, stated plainly. A synthesized-audio protocol perfectly controls speaker, channel and noise variation — every model is scored on exactly the same signal — but it does not reproduce real clinic acoustics: background noise, disfluency, overlapping speech, or genuine speaker accent variation. Absolute WER figures here should therefore be read as a lower bound on real-world error, and the protocol's value is in relative model comparison, not in predicting field accuracy.

3. Evaluation metrics & why they are appropriate

MetricDefinitionWhy appropriate for this task
WER Word-level Levenshtein edit distance ÷ reference word count. Industry-standard, comparable to all published ASR literature. But it treats a clitic-merge (jinin ki→jininki) as a full error, which systematically over-penalizes agglutinative and tone-marked African orthographies. Reported, but never alone.
CER Character-level edit distance ÷ reference character count. The load-bearing metric for this benchmark. Robust to tokenization and orthographic variance, so it separates "spelled the tone mark differently" from "misheard the drug name" — a distinction WER cannot make in Hausa, Yoruba or Igbo.
Accuracy 1 − WER, floored at 0. Not a research metric; included because clinic administrators and procurement staff — the people who decide whether to deploy this — read "78% accurate" and not "0.222 WER".
BLEU / chrF n-gram / character-n-gram overlap against reference translation. Downstream translation quality. chrF is weighted more heavily than BLEU here because it is markedly more reliable for morphologically rich languages where valid translations differ in surface word form.
AfriCOMET Learned neural translation metric tuned on African languages. Correlates with human judgement where BLEU does not, precisely for the low-resource languages in scope.
Clinical error
weighting		 Counts of medical-term errors, named-entity errors, and code-switch boundary errors. The metric that actually matters for patient safety. A 20% WER spread across function words is an annoyance; a 20% WER concentrated in drug names, dosages or allergies is a clinical incident. These are counted separately so the two can never be confused.

5. Qualitative findings

5a. The measured case, in full MEASURED

REFERENCE (ha) — AHMB-HA-001, antenatal iron/folate counselling
Kina bukatar shan maganin iron da folic acid a kowace rana don karfafa jinin ki da lafiyar jaririn.

GEMINI HYPOTHESIS — WER 0.222 / CER 0.025
kina buƙatar shan maganin iron da folic acid a kowace rana don ƙarfafa jininki da lafiyar jaririn

Every single counted error is orthographic, not acoustic:

  • ƙ vs k (2 errors). The model wrote the hooked consonant ƙ in buƙatar and ƙarfafa. This is correct standard Hausa orthography — the reference used the ASCII-fallback k. The model was penalized for being more orthographically correct than its ground truth.
  • Clitic merge (1 substitution + 1 deletion). jinin ki ("your blood") written as the equally valid bound form jininki. Two word-level errors for a whitespace decision that changes nothing a patient or clinician would hear or understand.
  • Clinical payload: perfect. iron, folic acid, kowace rana (daily frequency) — the drug names, the dosage schedule, the entire actionable content — transcribed without error.

Implication for deployment: had we ranked models on WER alone, we would have recorded a 22% error rate on an utterance that is clinically flawless. Any procurement decision or model-selection process for African-language clinical ASR that reports WER without CER alongside it is measuring orthographic convention and calling it accuracy.

6. Limitations & reproduction

Known limitations

  • n=1 measured instance. Free-tier quota (≈1 instance/min, 20 requests/day; 2 calls per instance) capped live evaluation. The measured figure is a verified single observation, not a distribution — no variance or confidence interval is claimed.
  • Sahara unverified locally — egress-blocked (HTTP 403), not a code defect; the integration is implemented and configured.
  • Synthesized, not recorded, audio — see §2. Absolute figures are a lower bound on field error.
  • Model B / Model C ship as an honest bring-your-own-endpoint extension point and report "not configured" rather than emitting placeholder numbers.

Reproducing this run

Set GEMINI_API_KEY and SAHARA_API_KEY, then from an unrestricted network:

curl -X POST $HOST/api/benchmark/run \
  -H "Content-Type: application/json" \
  -d '{"sampleIds":["AHMB-HA-001", ...],
     "selectedModels":["gemini","sahara"]}'

Or use the in-app Benchmark tab (?studio=1), which exposes per-instance selection, model selection, and the normalization switches. Every metric in §4a is computed by src/services/benchmark/{wer,cer,accuracy}.ts using standard Levenshtein edit distance with no weighting or score adjustment; the code is open in the repository.
